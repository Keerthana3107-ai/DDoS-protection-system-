# DDoS Protection System

## Overview
This is a mini project that demonstrates a basic DDoS protection system using Python and Flask. It monitors incoming requests and detects suspicious traffic based on a predefined request limit.

## Features
- Detects excessive requests
- Simple web interface
- Flask-based backend
- Easy to understand and modify

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run
1. Install Python.
2. Install the required packages:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   python app.py
   ```
4. Open the browser and visit:
   ```
   http://127.0.0.1:5000
   ```
